## Be aware: what was NOT verified
The code was written in a sandbox with **no access to PyPI, the Android SDK/Maven, Xcode or Swift**, and no Firebase/MongoDB instance. So:
- Backend (Flask port): the pytest suite (15 tests, in-memory repository) was **run and passes** in the sandbox, but with two small stand-ins for `pydantic-settings` and `flask-cors` (PyPI was unreachable, so those two packages could not be installed; Flask, pydantic and pytest were available). `test_mongo_repository.py` was skipped (needs `mongomock`). Never exercised: `gunicorn`, supervisor, real MongoDB/auth, `MinioPhotoStore`, Firebase token verification, FCM.
- Android: Java parsed for syntax only; **never built**. Missing imports or API mismatches are likely on first build.
- iOS: **never compiled** and the Xcode project is generated by `xcodegen` from `project.yml` (not yet run).
- Nothing was run against real Firebase, MongoDB or MinIO (token verification, FCM, GridFS, MinIO photos, reminder job).
- Languages (ar/fr/en) for errors, pushes, notifications, reminder titles and the email, and the FCM payload shape: tested with fakes (18 tests); never seen on a real phone. Arabic and French texts should be proof-read by a native speaker.
- Email verification code: tested with a fake mailer (16 tests); real Mailjet delivery was never tried (tested with a fake Mailjet client).
Plan for the first session: run `pytest`, build both apps, fix compile errors, then do the manual end-to-end checklist in DEVELOPMENT_GUIDE.md.

## Known gaps / not built
- Launch screens, dark-mode polish on Android custom screens. Server texts are translated (ar/fr/en); the apps' own strings are handled in the app repos.
- Android: no unit/UI tests; notification tap opens the app, not the specific animal; photo EXIF rotation not applied.
- iOS: notification tap does not deep-link; no offline cache.
- No offline mode on either app (needs a connection).
- One farm per person (members, roles and approval are done in the backend and both apps).
- Finance: no budgets/recurring entries; reports are CSV only (no PDF).
- Backend: no rate limiting, no audit log, no pagination beyond `limit`.
- Mockup has no finance, reports, notifications or settings screens.
